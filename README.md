# GenderGap Argentina

Dashboard de Exploración de la Brecha de Género de Ingresos en Argentina

## Instrucciones de uso

1. Descomprimir los archivos .zip dentro de la carpeta datos-eph/txt
2. Ejecutar el script procesar-datos-eph.R
3. Conectar el archivo .parquet generado a la herramienta deseada para su análisis (Power BI, Excel PowerQuery, etc.)
